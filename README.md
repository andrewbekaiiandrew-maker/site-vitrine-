# NovaShop

Site vitrine professionnel — création de sites web et bots Discord.

## Structure

```
site-vitrine/
├── index.html              Page principale
├── 404.html                Page d'erreur 404
├── css/
│   └── style.css           Styles (responsive + animations)
├── js/
│   └── script.js           Navigation, animations
├── images/                 Photos du site
```
